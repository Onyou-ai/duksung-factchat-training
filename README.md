# 덕성 FactChat 교육

덕성여자대학교 임직원·교수 대상 60분 FactChat(생성형 AI) 활용 교육 안내 페이지입니다.

## 배포

정적 HTML 한 장으로 구성되어 있어 별도 빌드 없이 Vercel에서 바로 배포할 수 있습니다.

1. 이 저장소를 Vercel에서 "Import Git Repository"로 연결합니다.
2. Framework Preset은 **Other**로 두고, Build Command·Output Directory는 비워둡니다.
3. Deploy를 누르면 `index.html`이 그대로 서빙됩니다.

## 수정이 필요한 부분

`index.html`의 신청 안내 섹션(placeholder 밑줄 표시)에 실제 값을 입력해 주세요.

- 일시
- 장소
- 신청 방법(링크)
- 문의처
- "신청 폼 바로가기" 버튼 링크
